# Timothy Boxho — Photographe (TYBox)

Site portfolio et vitrine professionnelle sur mesure pour l'activité de photographie de **Timothy Boxho** (Strasbourg · Alsace · Grand Est & France).

## Points clés de la refonte

- **Zéro dépendance & déploiement direct** : HTML5 sémantique, CSS3 moderne, JavaScript Vanilla (prêt pour GitHub Pages, Netlify, Cloudflare Pages ou hébergement classique).
- **Double thème Clair / Sombre** : bouton de bascule instantané dans l'en-tête avec mémorisation du choix (`localStorage`).
- **Bilingue FR / EN** : français par défaut (adapté au marché français et SEO local Strasbourg/Grand Est) avec bouton de traduction instantanée vers l'anglais.
- **Photos pleines couleurs** : aucun voile sombre terne sur les vignettes, chargement optimisé et visionneuse plein écran (Lightbox clavier + clic).
- **SEO & conversions corrigés** : `<h1>` et `<meta description>` uniques sur chaque page, balises `alt` descriptives, données structurées JSON-LD (`Photographer`), `sitemap.xml`, `robots.txt`, page **Prestations & FAQ**, et formulaire de devis sans bug (email + WhatsApp + copie).

## Prévisualiser en local (Windows)

Lance le serveur local PowerShell inclus :

```powershell
powershell -ExecutionPolicy Bypass -File .\preview.ps1
```

Puis ouvre `http://localhost:8765/`.
